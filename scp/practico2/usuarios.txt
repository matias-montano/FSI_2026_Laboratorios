Usuario: daguirre
Contraseña: contratreta
Servicio: Hash local del sistema
Herramienta utilizada: John the Ripper

Forma de obtención:
Se encontró el archivo shadow.bak, que contenía hashes de contraseñas del sistema en formato compatible con /etc/shadow. 
El hash del usuario daguirre fue crackeado de forma local/offline usando John the Ripper con el diccionario dic.txt.

Comando utilizado:
john --wordlist=dic.txt shadow.bak

Comando para mostrar las contraseñas encontradas:
john --show shadow.bak

Resultado obtenido:
daguirre:contratreta:20583:0:99999:7:::

Explicación:
John probó las palabras del diccionario dic.txt contra los hashes almacenados en shadow.bak. 
Cuando probó la palabra "contratreta", el hash generado coincidió con el hash almacenado para el usuario daguirre. 
Por eso se obtuvo la contraseña en texto claro.
