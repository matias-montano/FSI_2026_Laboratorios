## para comprimir y enviar

```bash
tar -czvf entrega4.tar.gz entrega4/
```
Explicación de las opciones:

- c : Crear un nuevo archivo tar
- z : Comprimir con gzip (para obtener .tar.gz)
- v : Modo verbose (muestra los archivos que se van comprimiendo)
- f : Especifica el nombre del archivo de salida
