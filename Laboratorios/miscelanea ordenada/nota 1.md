Para crear una carpeta en Linux usás `mkdir`.

Ejemplo:

```bash
mkdir practica1
```

Después entrás:

```bash
cd practica1
```

Y ahí podés copiar o mover archivos como `dict.txt` y tu lista de usuarios.

Si los archivos están en otro directorio:

```bash
cp /ruta/dict.txt .
cp /ruta/usuarios.txt .
```

El `.` significa “a la carpeta actual”.

Para ver que quedaron:

```bash
ls
```

Te debería mostrar algo como:

```bash
dict.txt  usuarios.txt
```
